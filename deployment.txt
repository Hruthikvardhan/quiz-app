2. GITHUB SETUP (Required before Vercel)
----------------------------------------------------------------

STEP 1 — Initialize Git in project
  Command:
    cd "your-project-folder"
    git init

STEP 2 — Create .gitignore file
  Content:
    node_modules/
    build/
    .env
    .env.local
    .DS_Store
    Thumbs.db
    .vscode/
    coverage/

STEP 3 — Stage all files
  Command:
    git add .

STEP 4 — First commit
  Command:
    git commit -m "QuizMaster - initial commit"

STEP 5 — Create repo on GitHub
  - Go to github.com
  - Click New repository
  - Name: quiz-app
  - Visibility: Public
  - Do NOT add README (already have one)
  - Click Create repository

STEP 6 — Connect and push
  Command:
    git branch -M main
    git remote add origin https://github.com/YOUR_USERNAME/quiz-app.git
    git push -u origin main

STEP 7 — Verify on GitHub
  - Open your GitHub repo URL
  - All files should be visible
  - node_modules should NOT be there

----------------------------------------------------------------
3. VERCEL DEPLOYMENT STEPS
----------------------------------------------------------------

STEP 1 — Create Vercel Account
  - Go to vercel.com
  - Click "Sign Up"
  - Choose "Continue with GitHub"
  - Authorize Vercel to access GitHub
  - Account created ✅

STEP 2 — Import Project
  - On Vercel dashboard click "Add New Project"
  - Click "Import" next to your quiz-app repository
  - Vercel automatically detects it is a React app

STEP 3 — Configure Build Settings
  Vercel auto-detects these for Create React App:
    Framework Preset : Create React App
    Build Command    : npm run build
    Output Directory : build
    Install Command  : npm install
  
  No changes needed — keep defaults ✅

STEP 4 — Environment Variables
  - Our app has NO environment variables
  - Open Trivia DB needs no API key
  - Skip this section ✅

STEP 5 — Deploy
  - Click "Deploy" button
  - Vercel runs:
      1. npm install   (installs dependencies)
      2. npm run build (creates optimized build)
      3. Deploys build folder to CDN
  - Takes about 1-2 minutes

STEP 6 — Get Your Live URL
  - Vercel gives URL like:
    https://quiz-app-hruthik.vercel.app
  - Click "Visit" to open your live app
  - Share this URL with anyone! 🌍

8. TROUBLESHOOTING COMMON ISSUES
----------------------------------------------------------------

  ISSUE: Build fails on Vercel
  FIX  : Run "npm run build" locally first
         Fix any errors shown, then push again

  ISSUE: App works locally but not on Vercel
  FIX  : Check browser console for errors
         Usually import path case sensitivity issue

  ISSUE: API not working on live site
  FIX  : Open Trivia DB works from any domain
         No CORS issues with this API

  ISSUE: Leaderboard not saving
  FIX  : localStorage works in production
         Check if browser is in private/incognito mode

  ISSUE: Old version showing after deploy
  FIX  : Hard refresh browser: Ctrl + Shift + R
         Or clear browser cache
